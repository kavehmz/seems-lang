The rule

            
Seems is Python with a few extra words. Every Python program is a valid Seems program, so every library works.
              Python operators are exact and run in code. A judgment verb sends the text after it to TypeSafe Jev.


if order.total > 500 and ticket.text asks for a refund:
    send_to_manager(ticket)
unsure:
    send_to_human(ticket)


            
Judgment verbs

            

              
FormVerbsAfter the verb

              
value VERB englishseems sounds looks mentions discusses describes expresses suggests asks requests
                Plain English. It ends at and, or, if, else, a comma, a closing bracket, a colon or the end of the line. Put it in quotes if it needs one of those, or an apostrophe.

              
value VERB valuecontradicts supports answers means matches
                A second value: a variable, or English in quotes.

            

            
A judgment is yes, no or unsure. It also has .p, the probability, and .verdict().


            
unsure

            
    
              
  • unsure: is an extra branch of if. It comes last.
    • 
              
  • Without it, an unsure judgment raises Unsure. Catch it like any exception.
    • 
              
  • and, or, not follow three-valued logic: no and unsure is no.
    • 
              
  • with seems.certainty(0.95): raises the bar inside the block.
    • 
            


            
kind, scale, judgment


kind team: "Which team should handle this ticket?"
    billing:   "payments, invoices, refunds"
    technical: "bugs, outages"
    other:     "none of these fit"

scale anger: "How angry is the customer?"
    calm:    "polite, no complaint"
    annoyed: "complains but stays civil"
    furious: "insults, threats, all caps"

judgment urgent: "Does this need an answer within one hour?"
    yes: "outage, money lost, legal deadline"
    no:  "general question, feedback"

owner = team(text)            # owner.name, owner.p("billing"), owner.sure
if owner == team.billing: ...
if anger(text) >= anger.annoyed: ...
if text seems urgent: ...     # one word after the verb can name a judgment


            
Speed

            
    
              
  • A judgment is lazy. Nothing is sent until the program needs an answer.
    • 
              
  • Then everything waiting goes together. Questions about the same value share one request.
    • 
              
  • An if / elif statement asks the judgments of all its branches in one round trip.
    • 
              
  • An exact "no" skips Jev completely.
    • 
              
  • For loops over independent items use seems.each(items, function), or build a list of judgments first.
    • 
            


            
Keep in code

            
Jev judges meaning. Math, counting, dates and exact lookups stay in Python. Jev reads very literally, so write the exact condition you mean.
